# Citation Tracking

The Citation module provides source attribution tracking for facts and claims generated by agents. It enables full traceability of where information comes from, supporting compliance, verification, and transparency requirements.

## Overview

Citation tracking in CEMAF follows a three-tier model:

1. **Citation**: A single source reference with metadata
2. **CitedFact**: A factual claim with supporting citations
3. **CitationRegistry**: Central registry tracking all citations in a run

## Core Components

### Citation

A `Citation` represents a single source that backs a factual claim. It includes:

- **Source identification**: `source_id`, `source_type` (document, url, database, api)
- **Metadata**: `title`, `url`, `author`, `date`, `page`, `section`
- **Quoted content**: Exact text excerpt (`quote`)
- **Confidence**: 0.0-1.0 confidence score
- **Custom metadata**: Extensible JSON metadata

```python
from cemaf.citation import Citation

citation = Citation(
    id="cite_abc123",
    source_id="doc_456",
    source_type="document",
    title="Research Paper on AI",
    url="https://example.com/paper.pdf",
    author="Jane Doe",
    quote="Large language models show emergent capabilities...",
    confidence=0.95,
)
```

### CitedFact

A `CitedFact` represents a factual claim with supporting citations:

```python
from cemaf.citation import CitedFact, Citation

fact = CitedFact(
    id="fact_001",
    fact="Large language models demonstrate emergent reasoning capabilities",
    citations=[citation1, citation2],
    confidence=0.9,
    verification_status=VerificationStatus.VERIFIED,
)
```

### CitationRegistry

The `CitationRegistry` maintains a central registry of all citations and facts:

```python
from cemaf.citation import CitationRegistry

registry = CitationRegistry()
registry.register(citation)
registry.register_fact(fact)

# Query citations
all_citations = registry.get_all_citations()
facts_by_status = registry.get_facts_by_status("verified")
```

## Provenance Cross-References

Citations now carry provenance metadata linking them to the exact LLM call and context sources that produced them:

```python
from cemaf.citation import Citation
from cemaf.core.enums import VerificationStatus

citation = Citation(
    id="cite_abc123",
    source_id="doc_456",
    source_type="document",
    title="Research Paper",
    quote="...",
    confidence=0.95,
    # Provenance fields
    agent_id="librarian",
    node_id="step_0",
    provenance_link_id="prov_xyz",  # Links to ProvenanceLink
    retrieved_at=datetime.now(UTC),
    context_path="context.sources.doc_456",
)
```

### Verification Status

`CitedFact` uses the `VerificationStatus` enum for type-safe verification tracking:

```python
from cemaf.core.enums import VerificationStatus

# VerificationStatus.UNVERIFIED  - Default, not yet checked
# VerificationStatus.VERIFIED    - Confirmed against source
# VerificationStatus.DISPUTED    - Conflicting evidence found
# VerificationStatus.RETRACTED   - Source was retracted
```

### Glass Box Citation Coverage

The `GlassBoxReporter` verifies that every citation refers to a source the LLM actually saw:

```python
from cemaf.observability.glass_box import GlassBoxReporter

reporter = GlassBoxReporter()
coverage = reporter.verify_citation_coverage(record=run_record)

print(f"Verified: {coverage.verified_citations}/{coverage.total_citations}")
print(f"Coverage ratio: {coverage.coverage_ratio:.0%}")
if coverage.unverified_ids:
    print(f"Warning: orphan citations {coverage.unverified_ids}")
```

## CitationTracker

The `CitationTracker` provides a high-level interface for tracking citations through the retrieval and generation pipeline:

```python
from cemaf.citation import CitationTracker
from cemaf.retrieval import SearchResult

tracker = CitationTracker()

# Track citations from retrieval results
results = await vector_store.search("query", k=5)
citations = tracker.track_search_results(results)

# Create cited facts
fact = tracker.create_cited_fact(
    fact="The sky is blue",
    citations=citations,
    confidence=0.95,
)

# Generate citation report
report = tracker.get_citation_report()
```

### Integration with Retrieval

`CitationTracker` automatically extracts metadata from `SearchResult` objects:

```python
# SearchResult from vector store
result = SearchResult(
    document=Document(
        id="doc_123",
        content="...",
        metadata={
            "title": "Research Paper",
            "url": "https://example.com/paper.pdf",
            "author": "Jane Doe",
        }
    ),
    score=0.95,
)

# Automatically creates citation with metadata
citation = tracker.track_search_result(result)
```

## Validation Rules

CEMAF provides validation rules for citation quality:

### CitationFormatRule

Validates citation format and completeness:

```python
from cemaf.citation import CitationFormatRule

rule = CitationFormatRule(
    require_url=True,
    require_author=True,
    min_confidence=0.8,
)

result = rule.validate(citation)
if not result.valid:
    print(result.errors)
```

### CitationRequiredRule

Ensures facts have supporting citations:

```python
from cemaf.citation import CitationRequiredRule

rule = CitationRequiredRule(min_citations=1)
result = rule.validate(fact)
```

## Integration with Context Patches

Citations can be tracked as context patches for full provenance:

```python
from cemaf.context import ContextPatch, PatchSource

# Create patch with citation metadata
patch = ContextPatch.set(
    path="facts.claim_123",
    value=fact.fact,
    source=PatchSource.TOOL,
    source_id="citation_tracker",
    metadata={
        "citations": [c.to_dict() for c in fact.citations],
        "confidence": fact.confidence,
    },
)
```

## Event Integration

`CitationTracker` integrates with the EventBus for observability:

```python
from cemaf.events import EventBus

event_bus = EventBus()
tracker = CitationTracker(event_bus=event_bus)

# Events emitted:
# - citation.added: When a citation is registered
# - fact.created: When a cited fact is created
# - fact.verified: When a fact is verified
```

## Usage Patterns

### Pattern 1: Retrieval → Citation → Fact

```python
# 1. Retrieve relevant documents
results = await vector_store.search(query, k=5)

# 2. Track as citations
citations = tracker.track_search_results(results)

# 3. Generate fact with citations
fact = tracker.create_cited_fact(
    fact=generated_claim,
    citations=citations,
)
```

### Pattern 2: Multi-Source Citation

```python
# Aggregate citations from multiple sources
web_citations = tracker.track_search_results(web_results)
db_citations = tracker.track_search_results(db_results)

all_citations = web_citations + db_citations
fact = tracker.create_cited_fact(
    fact=claim,
    citations=all_citations,
)
```

### Pattern 3: Citation Verification

```python
# Create fact with unverified status
fact = tracker.create_cited_fact(
    fact=claim,
    citations=citations,
    verification_status="unverified",
)

# Later verify
tracker.verify_fact(fact.id, confidence=0.95)
```

## Best Practices

1. **Always track retrieval results**: Convert `SearchResult` objects to citations immediately
2. **Include quotes**: Store exact quoted text for verification
3. **Set confidence scores**: Reflect uncertainty in source quality
4. **Verify facts**: Mark facts as verified when validated
5. **Use metadata**: Store domain-specific information in citation metadata
6. **Integrate with patches**: Link citations to context patches for full traceability
